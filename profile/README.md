## Azeroth Fellowship

We build open-source tools for World of Warcraft players who like looking back on the road they took. A small addon
records what your character does, a desktop companion uploads it, and the website turns it into a journey you can read
and share with friends, even when the game is closed.

### Projects

| Repository | What it is |
| --- | --- |
| [**journey**](https://github.com/azeroth-fellowship/journey) | The open-source parts of Azeroth Journey: the WoW addon, the Tauri desktop companion and the shared API contracts. |

### Principles

- **Private by default.** Nothing is shared until you choose to share it, and history and live location are separate permissions.
- **History first.** Your journey stays useful when the game is closed. Live presence is a bonus, not a requirement.
- **Open where it matters.** The code that runs on your machine is GPL-3.0 and readable.
